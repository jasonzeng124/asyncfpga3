# How to build the collapsed view, loop certificate and settling theorems for another decoded netlist

Works on any Spec netlist generated by shard A's `tools-A/target/gen_lean.py` (gate i drives node i,
chunks of 2500 gates, a `boundary` with `env`).

1. JSON of the committed Lean data (so the certificate is about exactly that netlist):
   `python3 formal/tools-B/target/lean2json.py formal/lean/Formal/Target/<NetDir> /tmp/net.json /tmp/arbs.json`
2. Explore (untrusted): `python3 formal/tools/cview/cview.py /tmp/net.json` (logic gates, chain lengths, sources);
   `python3 formal/tools/loops/loops.py /tmp/net.json` (SCCs after cutting storage self-loops);
   `python3 formal/tools/cview/loopobl.py /tmp/net.json <corner> out.tsv` (static storage-node switch table).
3. Generate Lean (namespace is fixed to `Formal.Net.CViewPS` in the generators: copy them and change `NS`,
   the `open Formal.Target.DecodedPS` line and the output directory for another target):
   `python3 formal/tools/cview/gen_lean.py /tmp/net.json formal/lean/Formal/Target/<NetDir>/All.lean <OUT>`
   `python3 formal/tools/cview/gen_rank.py  /tmp/net.json formal/lean/Formal/Target/<NetDir>/All.lean <OUT>`
   and copy `Base.lean`, `Collapsed.lean`, `HuffmanPS.lean`, `Settle.lean`, `Quiet.lean` (hand-written glue).
4. Build: `formal/slot.sh lake build <NS>.Quiet` (each T/V/K chunk is one ~40 s `decide +kernel`; ~25 min on 4
   cores for 75 chunks), then `#print axioms` of `collapsed`, `comb_ranked`, `settle_PS`, `quiet_PS`.
If `gen_rank.py` asserts "combinational part is cyclic", the netlist has a loop that does not go through a
storage LUT (a self-loop LUT); that is a finding, not a generator bug.
