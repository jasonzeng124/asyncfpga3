## The theorem

```
theorem gcd_hw_circuit_safe (a b : Nat) (ch : Fin NC → Chan)
    (H_CELLS : ∀ o : Fin NO, Cell ch (srcV a b) (opAt o))
    (H_BUNDLE : ∀ c, Held (ch c))
    (H_CM_FORCED : ∃ y, Good a b y ∧ ∀ o : Fin NO, Forced ch (omOf a b y) (opAt o)) :
    (∀ k e, TokAt (ch out0) k e → (ch out0).dat e = Nat.gcd a b) ∧
    (∀ t, closedVals (ch out0) t = List.replicate (cnt (fallB (ch out0).ack) t) (Nat.gcd a b))
```

- **The run.** `ch` gives the request, acknowledge and bus traces of every channel of the
  concrete network. That includes every bd_link segment, the joined (cond, data) channel of each
  branch, and the arbiter outputs.
- **The conclusion.** Every value the circuit ever latches on `out0` is `gcd a b`. At every time,
  the latched list is `gcd a b` repeated once per close so far.
- **H_CM_FORCED.**
  - It asks for a complete token run `y` of the GcdHw graph from `init a b`, meaning `Good a b y`:
    a traced run that ends in `final (gcd a b)`, with all its invariants.
  - It then asks that, on every token an arbiter stage offers, the circuit's winner (`CM.winner`)
    equals that run's label.
  - `cm_oracle_exists` proves that such a run exists for `a, b < 2^31`. That is why the range
    hypothesis is not an argument of the theorem.
  - For other inputs no complete run exists. H_CM_FORCED is then false and the theorem is
    vacuous. That is correct: in C, negative inputs loop forever.

## How it works

**O2, the solution.**
- **The run.** `good_exists` turns C-8i's complete run into a traced run.
- **H-class channels.** Their solution is the GcdHw channel's history, repeated forever (`perL`).
  If that channel carries no token in this invocation (data dependent, e.g. `a = 0`), the
  solution is a concrete default instead.
  - The defaults are computed by netgen.
  - They are checked by `OpChk`, as the "all-empty" instance of each equation.
  - Mux defaults follow input 0, which cuts every loop.
- **Ghost channels.** Their solution is defined by their producer's equation:
  - control channels and their copies;
  - the outputs of control steers, which are `0`;
  - each branch's joined bus `2·data + cond%2`;
  - the arbiter buses `2·(selected) + won`.
  These definitions are ranked and checked (`rank_ok`).
- **Why periodic works.** The final store is empty except on `out0`/`end`, and the env consumes
  those. The per-rule invariants (`FkI`/`CpI`/`BrI`/`MxI`) therefore hold of one period.
  `cnt_per`, `filter_rank` and `sel_rank` extend them to every index.
  - The mux and arbiter oracles are read from the index channel's history.
  - The 3-input cascade's stage-1 oracle reads the label among the non-2 labels (`W.lo3`).
    `selD_eq` proves that the circuit's 2-bit index equals the token label.
- **The end.** `out0`'s solution is `perL [gcd a b] 0 = gcd a b`. `Capstone.latched_const`
  (8l) concludes.

**O7, the network** (`netgen.py`; one row per GcdHw rule, following `bdc/emit.py`):
- **fork** → bd_fork.
- **comp** → bd_join + compute (`Join` with `g = e.subst σ`).
- **zero-delay comp** (`constant2`, `constant18`, `trunci0..4`, `extui0/1`) → no operator; the
  output is the input's handshake.
  - trunci/constant fold into the consuming join (`J.fold`, `J.const`).
  - extui folds into the producing steer's `f`. Both outputs of cond_br17 carry the same extui.
- **branch** → bd_join(cond, data) + bd_steer. Data branches use `steerD`; the 9 control
  branches use `steerC`, with ghost output 0.
- **mux** → bd_mux, or bdc_muxn3 for mux21.
- **control_merge** → bd_fork when it has 1 input. With 2 inputs it is bdc_amerge2 + bd_fork.
  With 3 inputs it is 2 arbiter stages + bd_fork (8l's cascade). That gives 9 arbiter stages in
  all.
- **links** → each linked channel is split into segments joined by bd_link operators (175). A
  folded channel's group carries the sum of its members' stages.
- **environment** → sources for a, b and start; sinks for out0 and end.

**Checker.**
- `OpChk` ties each operator to a GcdHw rule through explicit witnesses.
- `decide` checks it for all 367 operators.
- The negative controls show that it rejects a wrong data function and a swapped mux.

  steer, mux and amerge to B's generated cells). O4 is still open; the link is bound.

**H_BUNDLE.** It covers all 465 channels: the §3 per-channel and per-link timing obligations
(rules A, E, I, H, W, F, J, R) under §3's global tcheck hypotheses. Three kinds are ghost or
virtual channels:
- the 38 branch-joined buses (`jL`) are the steer select's bundling, i.e. rule E;
- the 9 arbiter buses (`zR`/`accR`) are B's H_BUNDLED_IDX;
- control (W=0) channels have no physical bus, so their H_BUNDLE is about the ghost value only.

**H_CM_FORCED (O1).** Open; see the last section.

**Token level (§1):**
- H_OPS_VERILOG and H_FUSED_EXACT: unchanged (grade A, in `rules`).
- H_ONE_INVOCATION: proved, used inside C-8i.
- **H_FIFO_UNBOUNDED: no longer used for safety.** The solution is capacity-independent.
- **H_SOURCE_ETERNAL: no longer needed for safety.**
  - The eternal source chains are simply not modelled.
  - A real join with extra inputs satisfies the `Join` gate model on a subset of its inputs:
    `cel` and `wire` only weaken.
  - The constant's bus is the literal bdc emits, and the model's `g` uses that literal.
  - It is still needed for liveness.
- H_DRIFT: `check_net.sh` plus C-8l's `check_links.sh` plus `dfimport/check.sh`.

**New modelling decisions** (grade them as stated):
- **H_GHOST (new, A for safety).**
  - W=0 channels and the arbiter's composite bus `2·data + won` carry ghost values, fixed by the
    gate models. Control steers output 0, so every ghost loop is cut.
  - The real index buses are images of the ghost buses: `won` = bus mod 2 (`sel2`); bdc_muxn3's
    index is `selD` of the stage-2 bus.
  - A real run extends to ghost buses meeting `Cell`. The ghost dataflow is feed-forward except
    through links, whose latches follow the real latch timing.
- **H_FOLD (new, B).** For a consumer-folded reshape, the model bus of the merged channel
  carries the pre-reshape value; the real bus is its bit selection. Every model gate on that
  channel is a copy (link latch) or the consumer's function, so the real traces are the image
  of a model run. A constant's trigger bus is ignored.
- **Not shown: a network-level non-vacuity run.** The all-quiet run meets every hypothesis and
  latches nothing. A run that delivers `out0` is O5 (liveness). 8l's per-cell witnesses remain
  the only non-vacuity evidence for the gate models.

**Proof obligations:**
- O2 closed, O7 closed, O3 closed (8l).
- O1 open (as a named hypothesis), O4 open, O5 open, O6 open.

## What O1 still needs (exactly)

For each of the 9 arbiter stages `o = .amerge x y z w`, prove from the gate models and H_BUNDLE
that, on every token `k` offered on `z`, `CM.winner (ch z) k = omOf a b y w k` for one complete
token run `y`. The route (unchanged from 8l):

1. **Per-operator causality counters.** For every cell, `#offers out ≤ #offers in` consumed.
   These counters exist inside each cell's invariant (`finv`, `JInv`, `SInv`, mux/amerge
   tables) but are not exported.
2. **The simulation.** The vector of per-channel offer counts of the circuit at any time is a
   reachable cut of the token LTS: a prefix of some run `y`.
3. **Forcing.** By `cm_inputs_exclusive` (8l), at that cut only one arbiter input can be pending.
   So the arbiter's grant equals the label `y` assigns.

The run `y` must then be shown complete (extended to `final`) with the same labels on the
prefix. `gcd_hw_graph_live` gives the extension, and confluence (`diamondG`) keeps the labels.

## Surprises

- H_SOURCE_ETERNAL and H_FIFO_UNBOUNDED both drop out of the safety theorem. Dropping a join
  input only weakens the `Join` model, and the stream solution never looks at capacity.
- Empty histories are data dependent (e.g. `a = 0` never enters the loops). The total solution
  therefore needs per-channel defaults solving the "all-empty" equations. Mux defaults follow
  input 0, which cuts every loop, so concrete defaults exist and are checked.
- Kernel `decide` over `∀ o : Fin 367` with list lookups ran out of memory (> 3.8 GB). The same
  check written as a Bool list traversal took 9 s.
- H_CM_FORCED is stated existentially, as "the labels of SOME complete token run". It is weaker
  than "the canonical labels", and it is exactly what an O1 simulation would produce.
