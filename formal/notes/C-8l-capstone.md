## Goal 1: the cells

**Link (`OpsLink`).**
- **Model.** The node `c` moves only to `ctlB (req_in, ack_out, c, rst=0)`. This is B's
  `LinkHandshake.ctlB`, which Gen's `bd_link_ctl_gate_B` proves equal to the LUT synthesized from
  the RTL: this is the only cell bound to the generated netlist with no hand step.
- `ack_in` and `req_out` follow `c` through separate unbounded inertial delays (the DACK and
  DELAY lines). They are not isochronic.
- The latch is transparent while `c` is high (H_LATCH_COMB).
- **Reachable set.** Python finds 18 states with two counters, `d = 1 + #req_out↑ − #ack_in↓` and
  `q = 1 + #ack_in↑ − #ack_out↓`. Lean re-checks the closure.
- `link_op`: `OpProto` + `OpData` with `σ o k = σ i k`. The offer facts come from the closure:
  - at an output offer, `c` is high at `r` and `r+1`;
  - the input is mid-transaction at both;
  - `d = 1` and `ack_in` does not fall, so the open input token is the k-th.
- `link_capacity`: `#ack_in↑ ≤ #ack_out↓ + 1` at every time. **One place.** This is the bound the
  bounded-FIFO bridge (O5) has to use; 8b's unbounded FIFOs have none.
- `link_held`: H_BUNDLE of the output follows from H_BUNDLE of the input. So in the zero-delay data
  model a link output needs no bundling hypothesis of its own. Its physical obligations are 8a's
  `Sep`/`Hold`/`SetupHold` (rules I, H, W).
- `link_witness`: non-vacuity.

**bdc_muxn3 (`OpsMuxN`, `OpsMuxNOp`).**
- **Model.** The same SI primitives as 8f's `Mux`, generalized to `j_k = C(in_k_req, ctl_req·(s==k))`
  for k < 3. `s = sel (ctl data)` is any function. Values ≥ 3 select nothing: the token waits
  forever, which is safe, and the state clips s to 3.
- **State space.** 13 wires + s (15-bit code): 648 reachable states, 594 with s < 3 (C-8j's
  number, a cross-check). The counters are a function of the state, so the whole table is one Nat
  bitmask `TB` with a byte per code.
- **Kernel cost.** Membership is kernel GMP arithmetic (`>>>`, `%`), not a list search. The closure
  is stated over all 2^13 wire combinations per select value, guarded by `mem`, in 4 declarations
  (plus 4 for the guarantees): 2 min 18 s at 2.9 GB peak, under the 4 GB cap.
- **Why the bitmask.** 8f's struct-list method scales as states × successors × list length. At
  648 states that is 20-40× its 132-state cost.
- `muxn_op`: the token equation `σ z k = σ (xs m) (#{i<k : sel(σ c i) = m})` for `m = sel (σ c k) < 3`.

**3-input control_merge (`amerge3_cascade`).**
- `emit_amerge(n = 3)` is a cascade: `uarb1` arbitrates in0 against in1 into an internal handshake
  `acc` (`R0`, `A0`), and `uarb2` arbitrates `acc` against in2.
- Each stage is exactly 8j's 2-input `AMerge` gate model:
  - `A0` of stage 1 is `A1 = C(g1, z_ack)` of stage 2;
  - stage 1's `R0` OR is an inertial node like the lumped OR + delay;
  - bdc's index `won2 ? 2 : won1` is a function of the two stage buses at one tick.
- So no new cell proof is needed. Two residual obligations:
  - H_BUNDLE on the virtual `acc` bus (= `won1`, B's H_BUNDLED_IDX).
  - **H_AMERGE_RTZ for stage 1. A finding:** stage 1 has no matched delay between `R0` and
    `acc_req`. Its return-to-zero race is one C-element LUT against three LUTs (ustate, ugrant,
    OR), not against a whole delay line. It is thinner than the stage 8j analysed, and no rule
    checks it.

## Goal 2: instantiating the refinement on gcd_hw

**Done.**
- `Wip/C8l/linkexport.py` runs bdc's own `Emitter` read-only, through C-8i's importer. It maps
  `linked`/`depth` onto the GcdHw channels: 109 linked SSA values become 100 channels and 175
  stages.
- 9 linked values lie on H_SOURCE_ETERNAL chains (`36#*`, `68#*`, `94#*`, `155#*`) and have no
  token-level channel. They are listed in the generated header.
- `latched_const` / `gcd_hw_conditional` give the end-to-end conclusion from a solution whose
  `out0` stream is constantly `gcd a b`: every latched `out0` value, and the latched list at every
  time, is `gcd a b` repeated.

**Not done, and why (O1, O2).**
- **O2. A total stream solution.** `Ops.net_refines` quantifies over total solutions
  `ref : C → Nat → Nat`. The token run is finite.
  - The plan: repeat the complete run's per-channel histories periodically (the sources repeat
    `a`, `b`, `start`). The final store is empty except `out0`/`end`, so every fork, comp, branch,
    mux and cm equation holds on the periodic extension, and `ref out0 ≡ gcd a b`.
  - What it needs: a generic lemma over GcdHwLib's `Rule.fire` (FIFO histories per rule kind; the
    mux's and the cm's index-counting form), plus the value conventions of bdc's lowering:
    - the control_merge bus `2·data + won` with W = 0, forked into result and index;
    - a 1-input control_merge = fork + constant index;
    - links splitting a channel.
  - Estimate 0.5-1 day.
- **O1. control_merge winner forcing.**
  - `amerge_op`'s equation is relative to the circuit's own winner stream `ω`. For an arbitrary
    `ω` a loop's stream equations can have no solution at all: the header picks the back edge
    before any back-edge token exists, so `z0 = f(z0)`. A solution exists for `ω` = the token
    run's labels. So the premise needs "circuit winners = token labels".
  - The argument. The token run's spine tokens form one causal chain (`closed_of_check`: a rule
    that puts a token on the spine takes one off it). Circuit offers respect token causality
    (each operator offers an output strictly after the offers it consumes). So when the circuit
    offers a header token, the only pending input is the one the token run uses.
  - What it needs: a per-operator causality lemma (#output offers bounded by the input offers
    they consume; the counters exist inside each cell's invariant but are not exported), and the
    simulation itself.
  - Estimate 1-2 days.
- **O4. Binding.** The Ops SI models of fork, join, steer and mux are hand models. B's
  generated-cell specs are timed FIFO-LUT models. No refinement lemma connects them (1 day). The
  link is bound.

**Decision (no one to ask).** I did not build the concrete Ops `Net` for gcd_hw: about 430
channels with the link splits, about 340 operators, and `Fin`-typed `prod`/`cons` checked by
decide. Without O1/O2 its only content would be bookkeeping, and the modelling decisions it needs
(the cm bus encoding, eternal chains) belong with O2. The time went to goal 1's completeness, the
ring proof, a non-vacuity run and goal 4.

## Goal 3: liveness

**Proved (structural).**
- `gcdhw_ring_ge3 : AllCyclesGe ringG 3`.
  - `ringG` has one node per fused firing rule (158) and one edge per channel from producer rule to
    consumer rule (265), weighted by bdc's link stages on that channel.
  - The proof uses C-9b's verified checker (`certCheckFrom_sound`). Python computes the
    certificate; the kernel checks it in 20 chunks.
- With C-9b's `allCyclesGe_iff_simple` this is CLAUDE.md's 3-stage rule on the fused graph that
  the circuit actually has. C-9b's `gcd_gcd_rd_ge3` (Wip) is the same fact on bdc's unfused
  handshake graph.
- `gcdhw_cycle_linked`: every cycle has a link. `gcdhw_has_cycle`: the graph has a 10-edge cycle
  with 7 stages (non-vacuity). `gcdhw_not_ge8`: negative control.
- **So the deadlock C-8j proved on 8b's hand-drawn graph (`OpsLive.gcd_loop_stuck`: a data loop
  with no storage) has no counterpart in the circuit bdc emits.**

**Open (O5): circuit liveness.** Three obstacles, in order:
1. **The Ops SI model has no progress.** Every gate is an unbounded inertial delay, so the
   all-quiet run satisfies every gate model and nothing ever HAS to fire. A liveness statement
   needs H_BOUNDED_DELAY per gate (Prelim's `BoundedDelay`, as in 8a's `muller_live` and 8e), or
   weak fairness.
2. **The token schedule must be carried to the circuit.** This is O1's simulation again.
3. **Capacity.** The token-level liveness (`gcd_hw_graph_live`) is for unbounded FIFOs, and a
   bounded run can deadlock where the unbounded one cannot (C-8k). The fix: show that one
   invocation never puts more than one token on any link stage (`link_capacity`), using
   H_ONE_INVOCATION. On the spine this is immediate. Off the spine it needs the per-channel
   occupancy of the schedule.
- The arbiters are not an obstacle under O1: with H_EXCL_REQ no arbiter ever sees a contest, so
  R3 (no metastability deadline) never applies.
- Estimate 2-3 days after O1.

## Surprises

- The 3-input control_merge needs no cell of its own: it is two `AMerge`s. Its first stage,
  though, has no matched delay, so its RTZ race is thin and unchecked.
- `Nat` bitmask membership in the kernel (GMP shifts) makes 600+-state closures cheap. 8f's
  list method would not have fit.
- 9 of bdc's links sit on source chains that the token model collapses (H_SOURCE_ETERNAL).
- In the SI/DI model, a link's output bundling is derivable (`link_held`).
