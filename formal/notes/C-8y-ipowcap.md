is proved. H_WALK is also proved, so the final theorem needs no token-level hypothesis.
The generic part is now a generator. A third kernel is cheap only if it has ipow's shape (see
the end).

slots). Core Lean only. No sorry, no axiom, no native-decide.

3. **Analogue of `gcd_hw_circuit_safe''`: proved.** `ipow_circuit_safe` (= `ipow_hw_circuit_safe''`)
   - Hypotheses: exactly gcd's named ones, with gcd's own gate models (`CapNet.Cell` is
     imported, not copied): H_CELLS, H_BUNDLE, H_START_ONCE, H_WALK.
   - Conclusion: every value latched on `out0` is `ipowSpec b e`, and the latched list at every
     time is that value repeated once per close.

4. **H_WALK: proved for ipow** (`ipow_hw_walk`, for every `b` and every i32 pattern `e < 2^32`).
   - This was not the plan. Probe 8s's H_WALK proof for gcd landed during this probe

5. **Generic vs kernel-specific (measured): 95 % of the Lean is gcd's text with names changed.**

   set. See the measurements below.

## The theorems (namespace `Formal.Net.IpowCap`)

```
theorem ipow_circuit_safe3 (b e : Nat) (he : e < 2 ^ 32) (ch : Fin NC → Chan)
    (H_CELLS : ∀ o : Fin NO, Cell ch (srcV b e) (opAt o))
    (H_BUNDLE : ∀ c, Held (ch c))
    (H_START_ONCE : ∀ t, cnt (riseB (ch start).req) t ≤ 1) :
    (∀ k v, TokAt (ch out0) k v → (ch out0).dat v = IpowHw.ipowSpec b e) ∧
    (∀ t, closedVals (ch out0) t = List.replicate (cnt (fallB (ch out0).ack) t) (IpowHw.ipowSpec b e))

theorem ipow_circuit_safe (b e : Nat) (ch : Fin NC → Chan) (H_CELLS …) (H_BUNDLE …) (H_START_ONCE …)
    (H_WALK : ∃ y, Good b e y ∧ WalkOK (σY b e y) (omOf b e y)) : (same conclusion)

theorem ipowhw_ring_ge3 : AllCyclesGe ringG 3        -- IpowCapRing
theorem ipowhw_not_ge4 : ¬ AllCyclesGe ringG 4
```

**What is assumed.**
- **H_CELLS:** every operator of the generated network meets its gate model. These are the
  8f/8j/8l cell models, the same `CapNet.Cell` as gcd's, so they carry §2 of
  `C-gcd_hw-hypotheses.md`.
- **H_BUNDLE:** every channel is bundled, as in §3.
- **H_START_ONCE:** `start` rises at most once.
- **`e < 2^32`.** That covers every i32 bit pattern.

**What is proved.** Every value the circuit ever latches on `out0` is `ipowSpec b e`. That is
`b^e mod 2^32` if `e < 2^31` (a non-negative i32), else 1, which is the C function's
result (8v's `ipowC_spec`). This holds for every run of the 101-channel network meeting the
hypotheses.

Intermediate results, all proved, with gcd's names under the `ipow_hw_` prefix:

| theorem | what it gives |
|---|---|
| `ipow_hw_forced` / `ipow_hw_forced3` | H_CM_FORCED at both arbiter stages |
| `ipow_hw_cut` | H_CUT |
| `ipow_hw_arbiters_uncontended3` | no free contention at either arbiter: the mutex never has to resolve a race |

**What it does NOT cover.**
- **Liveness.** All-quiet runs meet every hypothesis. No network-level run that delivers
  `out0` exists, as for gcd (O5).
- **O4.** The Ops hand models of fork, join, steer, mux and amerge are not bound to B's
  generated cells.
- **The DSP48E1 multiplies.** ipow's `muli` joins are modelled as combinational `g`
  (H_DATA_COMB), and their delay is inside H_BUNDLE. No DSP48E1 primitive model exists in shard C.
- **Knob settings.** Only bdc's default knobs, and the committed MLIR fixture.
- **H_FOLD / H_GHOST.** These are unchanged from 8m (the extui fold on cond_br4's outputs is
  the same pattern as gcd's cond_br17).
- **H_START_ONCE is assumed, not derived.** For `ipow_ps`, the host re-offers `start` by AXI
  register writes. One `bd_fork` drives b, e and start, and the host driver reads the result
  before the next write. That makes it grade B, depending on the host sequence. Unlike gcd_rig,
  there is no hardware env ring to derive it from.

The 148 changed lines break down as follows:
- **Mechanical renames:** namespace, `open` lines, theorem prefix `gcd_hw_` → `ipow_hw_`,
  `Nat.gcd a b` → `IpowHw.ipowSpec a b`, `GcdHw.Gcd.` → `IpowHw.`.
- **About 45 semantic substitution sites, driven by about 12 profile values:**
  - the out and end channels (57 and 4, for gcd's 250 and 3);
  - the default of `out0`'s descriptor (1, not 0: mux3's input 0 is the r = 1 literal);
  - `final_empty` via the kernel's `final_store_only`;
  - the existence theorem and its hypothesis (`e < 2^32` for `a, b < 2^31`);
  - `spL` / `start`;
  - the cascade constants of the walk proof (next paragraph).

**The walk proof's 3-input cascade** has no counterpart in ipow: ipow has 2 two-input
control_merges.
- **Mapping.** I did not delete those branches; I mapped gcd's constants to ipow values:
  - gcd's control_merge12 is rules 154/155 (`cm 13|27 → res 251, idx 249`). It maps to ipow's
    control_merge0, rules 19/20 (`cm 22|41 → 39, idx 40`). Every cascade fact the proof states
    is true there, and kernel-checked: `r154`, `r155`, `lab249_chk`, and the `lab` invariant.
  - `acc` maps to channel 0, which is not a spine channel. So the walk never takes the cascade
    branches, but they still type-check.
- **Cost.** This needed zero proof edits, at the price of a table entry that has to be
  explained. The negative control Neg3 shows that a wrong constant is rejected.

## How to run it on a third kernel (and what will break)

```
# 1. token level (C-8v's recipe): import with mlir2lean.py, prove <K>Hw{Proof,Live}.lean
#    (the C transcription, ~1 h), giving `<k>_hw_graph_computes_…`, init_store, final_store_only.
# 2. add a profile to capnet.py PROFILES and instantiate.py PROFILES (~25 lines), then
python3 formal/tools/capnet/capnet.py --kernel K links -o Formal/Net/<P>Links.lean
python3 formal/tools/capnet/capnet.py --kernel K ring  -o Formal/Net/<P>Ring.lean
python3 formal/tools/capnet/capnet.py --kernel K net   -o Formal/Net/<P>Net.lean
python3 formal/tools/capnet/instantiate.py --kernel K
lake build Formal.Net.<P>Walk ; python3 formal/tools/capnet/walkcheck.py --kernel K
```

For a kernel of ipow's shape this is about 30 min plus build time. ipow took 1 h 40 min,
including writing the tool.

**Tried on the other kernels:** `links`/`ring` work on all four (collatz, collatz64, xorshift,
isprime); Python finds a minimum of 3 link stages per cycle in each, which the Lean has not
re-checked. `net` refuses all four, with a clear error:
- **collatz, collatz64, isprime:** one data argument plus start on channels 0, 1. The gcd
  NetDef's `srcV a b` and `OpChk .src` hard-code "two data arguments, start = argument 2", and
  every copied file is written over `(a b)`.
  - **Fix:** about 2 to 3 h. Make the source table a profile list in the kernel slice of
    `OpChk` (already copied, so it is cheap), and give the kernel a 2-argument adapter
    (`init a _`) or substitute the arity.
  - **collatz** is additionally conditional (no total spec). Its `Good` would carry the
    `collatzC fuel n = some r` hypothesis.
- **xorshift:** a reshape (`extui`) folds into only ONE output of a steer. 8m's `FoldOK`
  requires both outputs to carry the same reshape. This needs a new `FoldOK` case and its
  soundness lemma in NetSound: about 1 to 2 h.
- **Walk proof:** a kernel needs at least one 2-input control_merge to host the cascade
  constants, or those branches must be deleted.

**The better long-term fix: parameterise the Lean instead of copying it.** Make SafeHist,
NetSound, CutSpine, Cut and Walk* take a `Kernel` structure: `rules`, `init`, `final`, spec,
the out and end channels, and `ins_ok`/`outs_ok`/`side_ok` as fields. That removes the 3081
duplicated lines. It means refactoring 8m/8r/8s's files. I did not do it, because those files
are other probes' and 8s's were still landing. The substitution table above lists exactly
which spots need parameters.

## Fidelity (beyond gcd_hw's, which carries over unchanged)

| item | grade |
|---|---|
| network structure | A while `capnet/check.sh` passes. It is the same construction as 8m (byte-identical on gcd), from bdc's graph and placement for ipow. |
| link placement | A. `Emitter.linked`/`.depth` with default knobs, as `build_hw.sh ipow_ps` runs it. |

| environment | `Src` per argument. `ipow_ps.v` drives b, e and start from one `bd_fork`, which is a special case of three four-phase sources. H_START_ONCE is B: it depends on the host driver offering the next invocation only after reading `out0`. |
| end token | `chEnd` (4) comes straight from start's fork (8v's finding), so the env sink's acknowledgement orders nothing. `ipow_ps.v` sinks it through `bd_delay`, which matches the `Sink` model. |

## Surprises

- **The whole gcd chain went through with ipow's constants on the first compile**, apart from
  two naming slips: a missing namespace qualifier on the spec, and a self-import. The
  only semantic difference was `out0`'s default descriptor (1 instead of 0).
  - So the 8m/8q/8r/8s proofs really are generic, and only their file headers bind them to gcd.
- **8s's H_WALK proof instantiated with no proof edits.** Its gcd-specific cascade branches
  could be kept by pointing their constants at an ipow control_merge that satisfies the same
  table facts.
- **ipow's ring bound is tight.** One cycle carries exactly 3 link stages. gcd's explicit
  cycle carried 7, and its tightness was not shown.
- **The other four kernels are refused by `net` for reasons of shape, not of semantics:**
  1-argument kernels, and a one-sided reshape fold.
