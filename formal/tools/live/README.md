# Liveness of bdc's circuits (shard C, 2026-11-18)

**The question (PROGRAM.md, owner 2026-11-18 16:48 UTC).** bdc deadlocked when a ring held as many tokens as stages
(`quadrec`) and the default flow hung on an inner loop with zero trips. State the condition a ring must meet, prove it or
check it exhaustively on the cell models, run it over every fixture, and tell research which fixtures fail.

**Answer, as of research 0cebd725c (bdc with the token floor and its pass-through modes):** no fixture fails. The condition
is "every closed walk of the stage graph holds a token"; in the stage model it is exactly right (Lean), and research's
arithmetic for rings and fork-join pairs is a theorem. Every emitting fixture is LIVE in formal's exhaustive model except
three that are only sampled, and every stage the floor adds is necessary. Answers to research: FOR-RESEARCH C53-C59.

## What is proved (Lean, `formal/lean/Formal/Net/`, core Lean, standard axioms)

| file | statement, plainly |
|---|---|
| StageNet.lean | Muller half-buffer stages, routing fixed, speed independent. A *trap* (a set of stages each with a token-free arc in from the set) is invariant under firing; no trap <=> no reachable deadlock <=> every stage fires infinitely often in weakly fair runs; a trap <=> a token-free closed walk (research's "short walk"). |
| StageNetCert.lean | a rank certificate rules out a trap; `Cert.check` is a decidable checker with a soundness proof. |
| StageNetRing.lean, StageNetMux.lean | the stage rule is the real bd_c2n LUT in run mode; bd_mux's join LUTs are C-elements in a fixed select. |
| StageNetGate.lean, StageNetTree.lean, StageNetTreeFair.lean | the gate network (C-element join / fork trees, buffer chains) refines the stage model: no trap in the stage bits => no gate deadlock, and every stage fires in fair gate runs. |
| StageNetRingLive.lean | a ring of S stages: no trap <=> 0 < D < S (D = differing neighbour pairs); at research's rest marking D = 2T (proved), so <=> T >= 1 and S >= 2T + 1. Any cycle with channels either way round (a fork-join pair): no trap <=> dF < F + dB and dB < B + dF, which at a rest marking is research's L_Q >= 2K. A trapped sub-cycle traps any network containing it. |
| LiveCerts.lean, LiveCertsPass.lean, LiveCertsKeepDepth.lean (2026-11-22: quadrec base / search forks / AUTO_SEARCH_KEEPDEPTH, 1 and 2 calls; graphs in keepdepth/graphs/) | 189 + 8 kernel-checked "no trap" certificates for the fixtures' routing modes (generated by gencert.py from live.py's stage-graph dumps; the generator is untrusted, the check is Lean's). |

**Not covered by Lean:** mode changes (entering, leaving and re-entering loops: the matrix / stencil_2d deadlocks were of
this kind), that the exported graph is the design, timing, glitches, X, data. Those rest on the untrusted search below.
