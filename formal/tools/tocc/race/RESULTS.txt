Verdict: NOT a counterexample.  A vs B is a real, unordered race (flips at kappa 0, both corners), but it is benign: it only
decides whether X22Y81.B5 glitches while every reader is closed.  The ordering that matters (A, B before the readers' re-open)
holds by Sep through the join X27Y80.D6(0), which waits for both.  The certificate fails because it builds D's claim as one
interval that covers the select change.  Fix: cut D's claim at B, and start the next segment at J (CovTime start with Sep from

goes to 0; sims at 0.44 still pass (197 ps).
