winchk.py: implemented, never run. What it encodes:
  Word = prefix (index 0) + main-loop windows (head SLICE_X39Y21.C5, window = floor((VCP-1)/2), as in win.py).
  Coordinates are window-relative as in Unroll.lean: rel = abs - off_i(node), and Lr = L - off_i(c), where
  L = VC (CF order with RT edges). A variant lowers L by the minimum over readers of ao's OVER, because the Lean
  uses ONE uL for all readers, while ao lowers L per reader.
  BackChain (UnrollTime): w :: w' :: ks => (forall u k, k < w'.len u -> forall alt in w'.causes u k, forall q in alt,
    -(w.len q.1) <= q.2). Checked on the physical alternatives only. RT reach is reported separately: it matters
    for SepWin, not BackChain.
  PairChain (UnrollAsm): forall a in Dv, c in Dv, 0 < w'.len a -> -(w.len c) <= w'.Lr a 0 c.
    In absolute terms: VC[first a in i+1, c] >= off_i(c), over every (a, c) in some D(v).
  StChain (UnrollData): w'.s0 u = xor (w.s0 u) (w.len u % 2 == 1). On one run this holds automatically, so the
    real check is that s0 depends only on the kind, on nodes that lie in some D(v).
  KindLStep (UnrollRest): has five disjuncts and is applied to wF (fc = alt ++ rt(e)). In absolute terms:
    u = c; or the first window and L <= 0; or the previous event lies in window i or i-1 and L <= L(prev); or for
    every fc alternative some q satisfies (q.1 = c and L <= idx q + 1) or (q lies in window >= i-1 and L <= L(q)).
    An empty fc list makes the last disjunct hold vacuously. Variants: L = VC, L = lowered, and L = VC with entries
    <= off_{i-1}(c) clamped to "none" (the candidate "pre-window fact" fix).
  KindRT/KindSub/KindNe: fc = [alt ++ rt e]. KindSub holds by construction. KindRT needs ao's form-iv Sep >= 1 on
    each RT edge.
  Kind invariance of len, causes, fc, Lr and s0 per kind, under three alphabets: (m, exit);
    + iterations 0 and 1 as their own kinds; + previous m.
  Also an --inner option (head SLICE_X38Y51.B5).

Expectations from reading the definitions against win/RESULTS.txt. These are NOT measured:

    Fix: iterations 0/1 in prefix kinds, or a static pre-window rule for rst.

    The (prev, kind) dependence of L should also force previous-kind information into the kind.
