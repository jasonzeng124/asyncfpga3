## 4. nextpnr's own number for the same arcs, re-derived (getPipDelay, xilinx/arch.h at bfdeaf7c)
# every non-TILE_ROUTING pip (site pip, site-pin entry/exit) = 25 ps; a CLB tie pass-transistor pip has
# max_delay 0 -> max(0, pip_epsilon) = 35 ps; a buffered pip = SLOW_MAX + R_pip * C_pip(its OWN in_cap).
#   vec[9].err_raw -> vec[9].uerr_s/A5 (pin B5):
#     SITEPIP COUTMUX 25 + site exit 25 + PT 35 + (138 + 1610.7*7.713e-3 = 150) + PT 35 + site entry 25 = 295   (SDF: 295)
#     prjxray: 0 (CMUX outpin) + 205 (C->>CMUX OUTMUX pseudo-pip) + 138 + 137 (pin B5) + 14 RC = 494 ps slow-max
#   umux10.either -> chain.g[0].u/A2 (pin A2):
#     SITEPIP 25 + exit 25 + PT 35 + (130 + 1162.2*8.429e-3 = 139) + (138 + 12 = 150) + PT 35 + entry 25 = 434  (SDF: 434)
#     prjxray: 130 + 138 + 507 (pin A2) + 60 RC = 835 ps slow-max
# The same re-derivation is in xray_delay.py (nextpnr_emulated_ps column): it reproduces nextpnr's SDF to
# within 1 ps on 41091/41096 non-clock arcs of gcd_hw, 7746/7749 of ro_many_top, 2444/2444 of ro_top and
# 8365/8456 of fresh7_ipow (the 91 misses are all the pad-input net rst, whose ILOGIC route-through the
# emulation charges as a 300 ps LUT route-through; nextpnr evidently does not).  Negative control
# (XRAY_NEGCTL_WRONG_PIP=1: each pip replaced by another pip out of the same wire): 483/2444 within 1 ps
# on ro_top -- the check fails as it should, and the 20% that still match are pips with identical timing
# classes, so the match is necessary, not sufficient.
