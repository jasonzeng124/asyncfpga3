## 1. phys2 / phys4 / phys5 (d6260627, 4232d569, 6f76d839)

### Headline theorems in plain words

`gcd_hw_circuit_safe_phys4` (Formal/Net/CapstoneRefine3.lean:96). For a, b < 2^31 and ANY
observed run `ch`:
1. H_CELLS_B: each of the 367 operators meets its relaxed gate model `CellB`. This covers the
   handshake behaviour and the DATA FIELDS while the output is busy, on the 26 roots too.
2. H_START_ONCE: `start` rises at most once.
3. H_TCHECK_ROOT: each of the 26 root channels (`rootIds3`: 21 mux outputs, out0 and 4 arbiter
   stages) has a `BCert`.

Conclusion: every out0 token value is gcd a b.

`BCert` (CapstoneRefineNet.lean:32-45) still has the constructor `exempt (h : Held P)`.

`gcd_hw_circuit_safe_phys5` (CapstoneRefine4.lean:138) replaces (1) by `CellP`: the handshake
half `HS`, and for each output EITHER the ghost data field `FieldOf` (the same field as in
CellB) OR a `Row`. A Row is a tcheck row, H_TXWIN, H_FN and H_LAUNCH. Hypotheses (2) and (3)
are unchanged. `phys5_hyps_of_phys4` (:228) shows phys4's hypotheses give phys5's, with every
output a ghost. So the ghost branch is an escape for EVERY channel, sampled ones included.

`_cls` (:175) forces Rows on exactly the 221 `sampIds`. `_gen` (CapstoneRefine4Fn.lean:274)
uses `RowG` (H_ZD_BITS + H_WIDTH) where `fnOK` holds and `Row` elsewhere.

### Findings

(a) The `exempt` escape still exists. It is confined to the 26 roots. phys4 does derive Held on
the other 439 channels (`gcd_hw_joint`, a real joint induction; `struct3_all` uses kernel
`decide`). That is genuine progress over phys (8x), which needed Held on all 465. The witnesses
`gcd_hw_phys4_witness` and `gcd_hw_phys5_witness` use `BCert.exempt` on every root and the ghost
branch on every output.

(b) NEW, and it makes the Row / tcheck branches unusable on gcd_hw. `TxWin.count : ∀ k,
cnt (riseB P.req) (τ k) = k` (CapstoneRefine.lean:191-199) needs a k-th transaction for EVERY
natural number k. So any channel with a TxWin is offered infinitely often. Auditor proofs in
F1_TxWin.lean:
- `txwin_inf`
- `bcert_fin_held`: on a channel offered finitely often, any BCert gives `Held` with no
  reset/receiver premise. The dag and cert constructors are impossible, so BCert = exempt.
- `row_inf` / `rowG_inf`
- `phys5cls_out0_inf`: the hypothesis of phys5_cls/phys5_gen forces out0 to be offered
  infinitely often from one start.
- `chW_not_cls`: the hypothesis of `gcd_hw_circuit_safe_phys5_cls` is FALSE on C-8t's run,
  which is the only gcd_hw witness. Every channel of chW has finite event lists (`chW_fin`).
- `chW_no_row`, `chW_bcert_is_held`

Consequences:
- "26 root certificates, all with tcheck A rows" cannot be realised in Lean for any terminating
  gcd run. The certificate there must be `exempt`, so H_TCHECK_ROOT is H_BUNDLE on 26 channels.
- phys5_cls and phys5_gen are vacuous on every run in which out0 (or any sampled channel) fires
  finitely often. That includes every physical single-start gcd computation.
- The journal's "a routed witness is the job of probe cap" cannot succeed with this TxWin.
- The toy `toy_row` works only because its channels are periodic (CapstoneRefine3FnWit.lean:25-34,
  period 20).
- Fix: index TxWin by k < number of offers (or by OffAt), not by all k.

(c) "phys2: H_ZD_AGREE removed": CONFIRMED. phys2 quantifies over the observed run `ch` directly,
with relaxed cells, so no agreement hypothesis is needed. H_BUNDLE is still relocated into BCert
(exempt) on all channels. phys3 cuts this to 31 roots, phys4 to 26.

(d) "phys4: protocol and Held derived for all 465 channels by one joint induction (H_SEND/H_RECV
gone)": CONFIRMED as Lean. Held on the 26 roots comes from BCert, which in practice is exempt (b).

(e) "phys5: data fields from tcheck rows, H_FN decided against Formal.Gen on 176/221". Recount

## 3. 10o ChainSettle (2fac68f3)

- `settled_iff` (ChainSettle.lean:373): `(∀ sig, AndRun net inp sig → ∀ t ∈ [A,B), sig z t =
  false) ↔ ∀ t ∈ [A,B), Lc net inp z t`. This is a real iff. The ← direction is soundness
  (`pin_low`, `cert_sound`). The → direction constructs an extremal run (`ext_bd`: "1 unless
  forced" is a BoundedDelay output; `extRun`).
- Quantifier order is correct: universal over runs on the left, and a per-t forced-low predicate
  on the right.
- It is not mere unfolding, but the RHS `Lc` is itself a recursive "forced-low" set. The closed
  form exists only for N = 2 (`chain2_settled_iff`, with side conditions).
- `runt_of_gap`: given Lc z x, Lc z y and ¬Lc z t with x < t < y, there is ONE run (the extremal
  one) where z is 0, 1, 0. That is a genuine runt. Quiescent at 0 only when inp 0 = true
  (`extRun_quiet`; the pulse satisfies this).
- Model scope: AND/OR networks, per-arc BoundedDelay (each event's delay chosen freely in
  [lo, hi]), LUT = Boolean function (no LUT-internal hazard).
- Not yet linked to O4's `GenChain`/H_CHAIN_SETTLED: the bridge (10o2) is in Wip/_snapC, which
  is not built.
- Docstring nit: `runt_example`'s docstring says T = 400. The code uses `pulse 1000 500`.
- "9 FASTFALL lines fail under the band only, all passed by rule F": MISCOUNTED. I counted from
  results.txt's disagreement list, which contains every exact FAIL because all rule-F margins
  are positive. 19 failing (line, model) rows = 1 sdfband + 9 fastG + 9 slowG, the same as the
  totals. They come from **11 distinct FASTFALL lines**:
  - collatz_2/3/4 uselect0
  - collatz_4 uaddi0
  - gcd_3 cm12, gcd_4 cm12
  - gcd_4 ushrsi3
  - xorshift_1/2/3 uxori1
  - xorshift_2 uxori2

  "9" is the per-model row count. "Under the band only" is right: they fail only in sdfband,
  fastG and slowG, where G = the corner widened by the 0.772/1.155 guard band (C-10e notes:84).
  tcheck's own VERDICT is fastG AND slowG (compare.py:80), so by tcheck's verdict these 11 lines
  FAIL. Rule F passes all of them (sdf margins +463..+2948): correct. The C-10o note's table
  lists all 11 lines, so the note is right and the journal sentence is wrong.

## 4. 8z4 CapstoneLiveNd4Serial / Mux (6e21b570)

- `serial` (Serial.lean:84) is a real generic theorem. If a set of simultaneous bit changes has
  a rank on the "disables" relation among changed bits, and each changed bit is excited toward
  its target in every intermediate state where none of its disablers has fired yet, then
  s →* s' in the interleaving semantics.
- `trace_reach` / `trace_nodead` iterate it and transfer an interleaving no-deadlock premise
  (H_INTERLEAVE, assumed) to the timed trace.
- `arb_not_reach` is a real necessity example. F3 `serial_needs_rank`: the arbiter tick
  00→11 satisfies `hex` with Dis = (≠) (`arb_hex`), has no rank (`arb_norank`), and is not
  reachable.
- `mux_out_not_mux`: `mux_out_chk` is `by decide +kernel` (kernel, not native_decide; no
  native_decide in any audited file, only a docstring mention in ChainSettle.lean:59). It says:
  for every operator, if it is a 2- or 3-way mux, the consumer of its output is not a mux.
  Purely structural. `hex` is not instantiated for gcd_hw, which the journal discloses, and
  H_NO_DEADLOCK'' stays OPEN.
