# T99 -- dynamic hold margins on the board routes (after T97's race-through)

T97 / research 00582e6b: on fxf2 seed 1 the counter's loop-back pipe stage takes the adder's NEXT result before it closes (a
hold race the static rules A/E/H do not audit when the sender is a compute unit with no link stage). Research says the
structure is in item 17's family. The audit's t83 latch monitor records, per data latch, the first data change within 2 ns
after each closing edge ("min_hold"); a race-through shows as a hold near 0 (fxf2 seed 1: **11 ps** at
ulink_n_trueResult_6 stage[0], with setup 22 ps).
