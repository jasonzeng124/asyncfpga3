## 2. What the counts are worth (OVERSTATED as "holds")

- **The draws are not independent across routes.**
  - draw:K takes every parameter from `random.Random(7919*K+17)`, and the setting-M scatter seed from K.
  - So draw K is the same delay model on every route, factor and item.
  - shrink1's "32/32" at x0.85 is 8 model points times 4 routes, not 32 model points. The per-factor model sample is 8.
- **Zero failures in n draws bounds the per-draw failure probability only weakly** (one-sided 95 %):

  | Draws | Bound |
  |---|---|
  | n = 8 | ≤ 31 % |
  | n = 16 | ≤ 17 % |
  | n = 24 | ≤ 12 % |
  | n = 32 | ≤ 8.9 % |

  "Holds to x0.40" rests on one route and 8 draws, so it is a passing fraction of 8/8 with a 95 % bound of 31 % failing.
- **The 8 shrink1 draws (K = 1..8) do not reach the model's own fast and skewed corners.**

  | Quantity | 8 shrink1 draws | 32 draws1 draws | Model allows |
  |---|---|---|---|
  | chains | 0.2165 - 0.3009 | 0.2000 - 0.3009 | 0.20 - 0.31 |
  | rest | 0.2252 - 0.3031 | 0.2043 - 0.3099 | 0.20 - 0.31 |
  | CARRY4 / F7F8 / FF | 0.4255 - 0.9869 | 0.2325 - 0.9869 | 0.20 - 1.0 |
  | max rest / chains (data slow against matched delay) | 1.31 | 1.50 | 1.55 |
  | max chains / rest (hold side) | 1.18 | 1.34 | 1.55 |

  - No shrink1 draw has chains or rest below 0.21.
  - The August kernels sit at x = 0.209-0.229 (T135). The fast end of the board's own measured range is therefore outside every shrink1 draw.
- **Shrinking matched delays is exactly the move that is judged at the "rest slow / chains fast" corner.** Those are the draws shrink1 sampled least: its worst ratio is 1.31 of a possible 1.55.
- **By the owner's rule (PROGRAM 501eda80d) this is OVERSTATED:**
  - the quoted fractions come without the model's error on board data (T135: open);
  - and they come without a stated confidence bound.
