## Details

### 1. Necessity2/3

`Necessity2Arb.Claim sp sg sa sG` restates `rt2_exclusion_arcs`. The restated copy is faithful: `RT2s D 0 0 0 0` has the same
fields as `ArbHeldTimed.RT2`, and `claim0` is proved from the shipped theorem. Still, I checked the rows
against the shipped `RT2` directly. `Nec.arb_g1` proves `Run DG1 SG1 ∧ Scn .. ∧ A0Fork DG1 ∧ pulse ∧ forkA ∧
forkG ∧ (g1 lhs = rhs + 1) ∧ ¬ RT2 DG1 ∧ ¬ ∀ t < 100, ¬(A1 ∧ A2)`.

Plain words: a run of the real arbiter LUTs, with the server answering in exactly smin. It meets every
hypothesis of the shipped theorem except one field, misses that field by 1 ps, and has both acks high
at 20.

The run uses c1f = 2 > c1r = 1. The one-corner variant `g1_false_1C` (rise = fall) exists because
prjxray gives no rise/fall split.

The other three sampled rows:
- `latch_pw`: RST0 (00B8..), transport latch inside point windows.
- `pipe_I`: N = 2, unit control run, ODD latches. The other DataN fields are carried verbatim from
  `dataS_I` (slack-free fields of DataS are textually identical to DataN; I diffed them).
- `arb_forkA`: the fork row of the arbiter.

All four are honest "necessary at one boundary point" results. They are not iffs, and the JSON does not
call them iffs.

### 2. KleeneBox

The X model is `lutK = muxTree init.testBit`, with mux(X, a, b) = a if a = b, else X. Inductively this is the exact
ternary closure. My independent `ext` (completions, then all-agree) matches it on 729 vectors for each of the
6 INITs. The `+w` results are iffs in binary-edge coordinates under H_X_UNIFORM. The definite-window
iffs (`steer_box_exact_K`, `join_box_exact_K`) have the same right side as the binary iffs.

### 3. CTreeExact

The quantifiers are in the table row. "For every behaviour" is literal: Good quantifies over every Sol
output, with the children's outputs existential and adversarial. It is restricted to monotone edge read
maps. The feedback maps are arbitrary within their box.

### 4. LinkExact

"Exact" = `↔`. Both directions are proved:
- `sufficient`;
- `need_*`, case-split in `exact`.

Each `need_*` assumes the earlier conjuncts.

Non-vacuity holds on both sides. P0 is safe, and a behaviour exists there. Each Pv i violates exactly one
conjunct by 1 ps (`Pv_one_tick`) and is unsafe. All of these lie inside Wf ∧ Split.

### 5. ArbPin / ArbPin2

Per-arbiter numbers trace back to an extraction that is not reproducible from this checkout. The Lean only
certifies that the stated verdicts follow from the stated 14-number boxes. I recomputed those boxes in
Python and they match the note's figures exactly (54, 33, -9/-30, 30/29/29/30, -631..+118, two fully safe
arbiters).

### 6. ResetGcdVec2

The derivation is real. The only per-cell objects (pinsOK for the 414 cells, the vecA facts) are decided
by `decide +kernel` over gNet, not assumed.
