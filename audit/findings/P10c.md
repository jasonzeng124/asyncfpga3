### 1. ResetCapstone: the virtual glue
- `gl r T0 c` is defined in ResetCapstoneGlue.lean:160:
  - `req t = if t < 3 then preR c t else (r c).req (t-3+T0)`;
  - ack is false in the prefix;
  - data in the prefix is r's data at T0.
- `glue_cells` proves `CellA r T0 ∧ AtS r T0 → ∀ o, Cell (gl r T0) _ (opAt o)`, per kind. `side_chk` is decided for 367 ops.
- `gcd_hw_safe_from_reset` transports only the out0 falls at C-time s+3, which correspond to e = s+T0 ≥ T0. Silicon is never claimed to have the prefix ticks, so the composition is sound.
- The weakness is not the glue. It is that after T0 the RTL run `v` and the C family `r` are unrelated except by assumption (H_CELLS_AFTER).
- Open hypotheses, as stated in the files and confirmed by the binders:
  - H_CELLS_AFTER (C's O4: SI models on the RTL);
  - H_MAP_T0;
  - H_START_AFTER (the rig re-offers start);
  - the 9 bd_src frontier links;
  - liveness.
- H_MAP itself is discharged in Bmap (μT, by decide). That the generator's rows are the RTL drivers is an untrusted-generator claim; it is reproducible byte for byte per the journal, but I did not re-run it.
