## Notes

**Hypotheses of gcd_hw_circuit_safe'', read to the base:**
- **H_CELLS** = per-op `Cell`. These are C's unit-time gate models: Fork, Join, Steer, Mux, MuxN, the AMerge with free grants (includes H_ARB_EXCL, never both grants), Link (Muller table), Src (`dat = a`, `b` or `0`; may re-offer when ack low), Sink. Each is a "may change only when enabled" relation, so silence is allowed.
- **H_BUNDLE** = `Held` on every channel.
- **H_START_ONCE** = at most one `start` req rise.
- **H_WALK** = `∃ y, Good a b y ∧ WalkOK (σY a b y) (omOf a b y)`. It mentions no circuit trace. It cannot assert out0's circuit value. It is a token-level fact about the run y of the GcdHw graph, and `Good` forces y to end at `final (Nat.gcd a b)`.
- None of these implies the conclusion by itself. The gcd content comes from `Good.fin` together with `eqn_sound` and the per-op `cell_op`.

**Remaining gaps:**
- **Liveness.** No run with an out0 latch is shown to satisfy H_CELLS ∧ H_START_ONCE, so the result is pure safety. An all-silent run satisfies every hypothesis, and C's own note admits this.
- **H_ARB_EXCL.** The AMerge model assumes discrete exclusivity. Formal's ArbOverlapRace bounds analog overlap at ≤ 33 ps, so this is an abstraction to keep in view.
- **Cell binding (O4).** H_CELLS has not yet been derived from the netlist or from B's timed models.
