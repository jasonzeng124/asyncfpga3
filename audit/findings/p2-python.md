## Notes for the auditor

* **C-10c headline.** The arithmetic and the reproduction are solid: a byte-identical rerun, plus an independent SDF walk that matches all 532 rings. The interpretive numbers 1.067 and 0.989 are calibrated to silicon by a global scale and compare **one** measured ring with simulated look-alikes from a different rig. Without the scale, the current SDF *over*-predicts ring 0 (0.939) and prjxray slow_max over-predicts by about 1.65x (0.605). With a 7-link-only scale, the current SDF under-predicts by 14% and prjxray by 8%. Quote "1.067 / 0.989" only together with "after a population scale fitted to silicon".
* **fid.** The checker can discriminate: it catches INIT flips and pin swaps, and it correctly ignores a bit that cannot be addressed. But its EQUIVALENT verdict did not reproduce on the route available here. The cause is a nextpnr JSON connection to GND that was never routed, and it is benign for these 3 LUTs. Worth a line in fasm_equiv's benign classification, and worth checking in nextpnr: a pin that JSON says is GND but that is VCC on the die would matter for a LUT whose INIT depends on it.
