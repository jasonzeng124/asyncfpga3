### (b) What is proved, in plain words
`design_verdict9arbnet_env` (Events9FullArb.lean:356-399) is the parallel-network verdict: given a recognized
design (Recog6, OK7, the derivation log, the per-pin certificates) and a behaviour x **with its warps**
(`SatPinW d plG x`), constants, a single reset released at T, and for every arbiter k: the checked ArbOK, OwnOK,
RsOK, FixShape, ArbRowsOKSS, 1 ≤ plo PqQ; plus the assumed hbase, QQuiet after S (`hQ`), `ArbEnv hsat rn (as k) T0
(H k)` and `ArbOrd hsat (as k) T0`. The conclusion: there is a token behaviour bh of the network such that,
under SelPart/SelOK and the residual obligations, every real node's output wire equals its phase function of
bh's counter. The proof is one line: `design_verdict9arbnet` with ArbCond from `arbCond_of_ordSP` and
`arbEdgeSP_of_env`. Axioms: propext, Classical.choice, Quot.sound (my #print axioms).

`ArbEnv hsat rn a T0 H` (Events9ArbB1.lean:937-963), every field (my `#print`, A_ArbEnv.out):
1. `reqlow`: both request wires r1S, r2S are low at every t ≤ T0 + 2. This is an environment/behaviour fact (T0 ≈ T + 2–7 ns in xarbnet's rows).
2. `stall`: every time v is within H of a time v' with v' = 0 or `Ok` at ustate time v' + 1 − K (A0 read high,
   or Settled: A0 read low and q constant for the rest of that A0-low phase). A behaviour fact: no A0-low phase has
   its last q change more than ~H after it starts.
3. `hi`: H + K + hi(DA) ≤ 10^15. Arithmetic on the parameter H and the bands. Not a behaviour fact; decidable.
4. `e1`..`e4` (`RdEdgeNF`, l.803-811), for readers g1 (r1, q), g2 (r2, !q), R0's r1 term, R0's r2 term (R0 bands − 2):
   `nore` (after q flips away at τ, the request is low on [fQ τ, τ + hiDq + 2 − loDr)), `rise` (after a request rise
   at σ, every ustate time u in [σ + loDr − hiDq, σ + hiDr + 2 − loDq) with e u is Settled), `flip` (after q flips
   toward at τ, every u in [τ, τ + hiDq + 2 − loDq) is Settled). **No time guard**: these quantify over all τ, σ ≥ 1,
   including power-up.
5. `c1`..`c4`: for t > T0, if the reader's request read fell between t − 2 and t, then ustate's A0 read at the
   reader's q-read time is high (on the supplied warps f1Of/f2Of/frOf/f4Of).

Every field except `hi` is a statement about x and its warps that a real run can falsify. Each is assumed, per arbiter.

6. **Discharged anywhere?** `grep ArbEnv|arbnet_env|ArbEdgeSP|arbnet_ordSP` outside Events9ArbB1/Events9FullArb: no

7. **Satisfiable?** (Part 5, `env_of_idle`, proved): if r1S, r2S ≡ false, qS constant, aS ≡ true and `hi` holds,

### (b) What the monitors compute
gen_evmon.py logs every change of q, A0, r1, r2 (driver nets) and writes info.json with the GLS point delays
(ICBUF D + TA of the pin): DA, DQ1/DQ2 (ustate's request pins), and per reader Dr/Dq. A0 and rst are picked from
ustate's INIT, each grant's request from its INIT, and the R0 reader takes the same request nets. check_env.py
evaluates, for t ≥ reset release, with xarbnet's slow bands:

| Lean field (RdEdgeNF / ArbEnv) | Lean window | check_env | match |
|---|---|---|---|
| nore | s low on [fQ τ, τ + hiDq + 2 − loDr), fQ τ = τ − DQ | [τ − DQ, τ + hiDq + 2 − loDr), s high or X = violation | yes |
| rise | u ∈ [σ + loDr − hiDq, σ + hiDr + 2 − loDq), e u → Settled u | settled_all(…, e_true) | yes |
| flip | u ∈ [τ, τ + hiDq + 2 − loDq) → Settled u | settled_all(τ, …) | yes |
| Settled u | A0(u − DA) = 0 ∧ q constant from u while that read stays low | non-settled = A0r high/X runs ∪ [p, last q change) of each A0r-low run | yes |
| c1..c4 | t > T0, r(t−2−Dr) = 1, r(t−Dr) = 0 → A0(t − Dq − DA) = 1, i.e. A0 high on [σ + Dr − Dq − DA, +2) | same, with reader point delays | yes (superset: from release, not T0) |
