## Claim 1: a234de9c InvolutionExp. Verdict: CONFIRMED (mathematics), with minor wording caveats

**Plain-words statement.** The channel is A's `ExpLog.expPair`, built with Mathlib's real exp and
log (`InvolutionExp.lean:46-62`):

    δ(T) = T_p + τ ln(2 − e^{−(T+T_p)/τ}),   δ∞ = T_p + τ ln 2.

- `expR_pulse_cancel_iff` (`:162`): an isolated pulse of width Δ > 0 is cancelled iff Δ ≤ τ ln 2.
- `expR_stat` and `expR_crit` (`:229`, `:246`): the OR loop has a unique stationary train
  w* = τ ln x, with x = (√(1+8e^{T_p/τ}) − 1)/2, and the critical runt is s* = T_p + τ ln(2/x).
- `exp_resolution` (`:440`): for 0 < s < δ∞ and s ≠ s*, a first cancellation index m exists,
  and m is odd (latched) iff s > s*.
- `exp_laps` and `exp_laps_log` (`:421`, `:454`) give two-sided bounds on m, with
  K(M) = r/(2−r) and κ = q/(2−q).

**Own maths check (`invexp_check.py`).**
- sympy simplifies −δ(−δ(T)) − T to 0, so δ is an involution.
- `expR_paper` agrees numerically with δ(T) to about 1e-16.
- The pulse threshold under the IDM cancellation rule flips exactly at τ ln 2 (tested at ±1e-9).
- Independent event-driven OR-loop simulation, written from scratch (not using A's orbit
  recurrence), with s* found by bisection:

  | (T_p, τ) | bisected s* | closed form |
  |---|---|---|
  | (0.3, 1) | 0.796368798767 | 0.796368798767 |
  | (1, 0.5) | 0.738137330760 | 0.738137330760 |
  | (0.396, 0.04) | 0.212099831774 | 0.212099831774 |

  Small s is lost and large s latches, which matches "odd iff s > s*".
- δ(−w*) − 2w* is about 1e-17.

**"Not an involution".** `badDelay` (`:109`) is exactly the brief's formula,
δ∞ + τ ln(1 − e^{−(T+δ∞−T_p)/τ}) with δ∞ = T_p + τ ln 2. The theorem `bad_not_involution` (`:114`)
proves −bad(−bad(0)) ≠ 0 for 0 < T_p < τ ln 2.
- Numerically: 0.131 at T_p = 0.3, 1.127 at T_p = 0.6 and 4.38 at T_p = 0.69 (τ = 1).
- Non-vacuity: `P12c_bad_inst` instantiates it at τ = 1, T_p = 1/4.
- `P12c_pulse_inst` shows that, with τ = T_p = 1, width 1/4 is cancelled and width 2 is not.
- The function used (`expR_paper`) matches the standard Függer et al. exp-channel shape with
  V_th = 1/2.

**Caveats.**
- (a) "not an involution" is proved only for T_p < τ ln 2. Above that, the formula leaves its
  domain at T = −T_p.
- (b) The headline "odd iff s > s*" assumes s ≠ s*. Behaviour at s* (an eternal train) is not
  restated here.
- (c) All of this is about a model channel. Reading TLOOP as δ∞ is a modelling choice, and the
  journal says so (`JOURNAL.md:701-711`).

## Claim 4: 550e5b27 XInert SoundInertial. Verdict: CONFIRMED (theorem); "Verilog default" OVERSTATED slightly in scope

**Plain words.** If every gate (a) has a real ps band [L, H] inside its parsed step band, with
L ≥ lo·u so that it is not a "raised" arc, and (b) is transport or `BoundedInertial ρ' L H` with
ρ' ≤ its window ρ, then the widened design satisfies `SatPhys`. Consequently xaudit's
noX/const/fixpoint/value verdicts on the widened design hold at every real instant
(`noXF_sound_inertial` etc., `SoundInertial.lean`). Further hypotheses:
- `Design.WF` of the widened design;
- inputs covered (`InputsCoveredT`);
- the parser and `applyInertial` are trusted.

`widened_wide` and `widenHi_eq_of_window` give exactly the case split. `checkedSteps_inverted`
rejects lo > hi.

**Verilog semantics.**
- `DelayInertial.Inertial δ := InertialRD δ δ`, which is `Filt δ` (rejection filter: the value
  at u is x τ for the latest τ ≤ u with x constant on [τ, τ+δ)) followed by a shift by δ
  (`Inertial.lean:58-63`).
- This matches IEEE 1364's inertial rule: a change that does not persist for the delay is
  rejected, and pulses shorter than δ are removed.
- Tie convention: a pulse of exactly δ passes. IEEE leaves the same-time ordering
  nondeterministic, so this is a choice, documented at `Inertial.lean:16-18`.
- Not covered, and not stated in the journal:
  - distinct rise/fall (/turn-off) delays (`#(r,f)` or SDF rise/fall IOPATH): `Inertial` has
    one symmetric δ;
  - X/Z output values;
  - PATHPULSE error limits smaller than reject limits (the X band).
- `gateOK_verilog` is a 3-line instantiation, with ρ = H (the band hi), which is sound since
  δ ≤ H.

**Scope of "gcd_hw seed d keeps smax certificates up to ρ 50 ps (discrete model only)"**
(`notes/A-xinert.md` table). This is accurate as written. But:
- under the actual "Verilog default" window (ρ = delay, LUT only), the smax w0 certificate is
  **lost** (no rig_lap; X from 79.7 / 35.2 ns);
- the ρ = delay-everywhere runs were killed.

So Verilog-default inertial is covered by the theorem, but gcd_hw has no certificate under it.
The journal entry (`JOURNAL.md:748-760`) mentions ρ ≥ 75 losing smax, but not the delay-LUT
loss. The journal also correctly says the 2334 raised arcs mean no gcd verdict is covered by
the continuous-time theorem at any ρ.
